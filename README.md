# PullOver Pro port development

This is an incomplete GPL-3.0 port of c1d3rdev/Will Smillie’s PullOver Pro. Main preserves Alpha4; the earlier tested picker/launch/rendering and Safari/Reminders source branches remain preserved.

Current isolated work is0.15.0~dev.favorites1 on debug/favorite-app-picker. It adds up to16 ordered persistent favorites, All/Favorites filtering, separate star targets and long-press quick selection. File work stays off main; private hosting, service, lifetime, keyboard/focus and window behavior remain unchanged apart from version/report names.
