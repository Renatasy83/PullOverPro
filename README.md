# PullOver Pro port

GPL-3.0 port of c1d3r / Will Smillie's PullOver Pro. **1.0.3 RC4** corrects the handle flow: first tap/inward pull reveals only the handle and choices; a separate second tap on the selected handle or an explicit choice opens the app. A grid button opens all applications. Row hit targets stay separate from the handle.

RC4 adds a strict audited Messages metadata profile and retains the latest capability result for eight distinct apps. **Actual Messages rendering/input and the new physical UI flow remain device-unconfirmed; Messenger is unresolved until its retained diagnostic is inspected.** Other complex clients are not enabled by guesswork. Private owner/admission/bridge/lock methods are unchanged, and the owned-trial change is report version/path only.

Source `8bd812121489f896f4e38d578da10ba0ce284039` passed **34 automated suites**, Clang analysis, pinned Theos rootless arm64/arm64e compilation and independent artifact/DEB/hash/payload checks. These do not prove full Dopamine/ElleKit compatibility, every-app support or exact upstream parity.
