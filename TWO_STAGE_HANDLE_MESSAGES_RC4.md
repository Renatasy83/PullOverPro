# RC4 — two-stage handle and narrow Messages profile

Version **1.0.3~rc4** follows the user's correction: the first handle tap or inward pull reveals only the expanded handle and app choices. It does not inspect the selected app for a scene, launch it or create a window. A separate second tap on the selected handle, or an explicit row selection, authorizes the existing checked open pipeline. A window already open can retract; a retained but retracted window also needs the reveal step before reopening.

The selected handle stays visible and separate from rows. Quick-choice geometry reserves its complete 44–72-point touch band; rows appear below/above without intercepting that handle. A dedicated grid button opens all applications, replacing the conflicting double-tap shortcut. Manual nubbing remains an independent outward action. Cancelled/stale pan terminals cannot open an app; selected-ID/generation binding and existing fresh metadata/owner checks remain required.
