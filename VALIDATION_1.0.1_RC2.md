## What changed

RC1 depended on an existing app scene. With a clean absent-source result, RC2 can construct the verified application identity and normal specification from a copied selected ID and fresh positive installed eligibility. The existing isolated owner/controller/workspace and activation path remain responsible for creating the new child. Runtime encodings, exact cold factory result classes, normal role, child namespace/ID/specification and proxy binding are checked. Missing, stale, malformed, negative, ambiguous or unsupported inputs refuse construction. Unknown ownership is quarantined; cleanup and replacement require existing proof. See [factory audit](OWNED_COLD_DEFINITION_AUDIT.md) and [activation trace](COLD_ACTIVATION_TRACE.md).

Cold activation must become active and produce an initial owned-layer observation within 8 seconds before Keep. Warm activation remains 2 seconds and optional timed mode 15 seconds. This policy cannot interrupt a blocked private call, and layer presence does not establish pixels or input. No separate suspended launcher, foreign scene write or guessed foreground/security/focus flag was introduced.

Default Sertar is now the original-aspect headerless edge panel. The handle moves to the opposite edge with its X; outside tap retracts it. Long press shows a narrow icon column, with hover/drag, upward ordering and bounded scroll. Double tap opens the full browser. A changed async projection cancels a held selection. Cached choice/favorites restore without launch or synchronous file I/O. Alternate size presets retain their toolbar/move/resize/minimize features. Exact private app icons, system-wide recent history, external keyboard adaptation and simultaneous windows are not claimed.

## Prior actual phone evidence and remaining limits

The supplied RC1 Safari JSON records a kept session closed manually after about 34.83 seconds, seven completed resizes and three moves. Framework identities match; its own controller/workspace cleanup is confirmed, unpinned and unpoisoned, and replacement is allowed. The user reports RC1 works. These observations do not establish RC2 cold startup, new compact gestures/geometry or every Settings control. Earlier app-specific observations remain in DEVICE_VALIDATION.md.

This CI run did not exercise real iOS launchd/entitlements, sandbox access, private framework construction/activation, cold process bootstrap, content pixels/input/keyboard, locking/orientation/app death, actual cleanup, watchdog behavior or PreferenceLoader discovery. No compatible physical Apple Silicon Mac is accessible for vphone-cli; neither Linux nor Intel Actions can substitute for the actual jailbroken target. Static firmware traces establish method shape/call paths, not authorization, readiness or runtime compatibility.
